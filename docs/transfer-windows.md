# 新电脑迁移说明（Windows x64 便携包）

这个包包含当前项目代码、npm 依赖、数据库、完整 data 目录、论文原文件、解析附件、页面缓存、历史结果、提示词、已生成报告和 `.env`。随包附带 Node 24、GPT Codex CLI、Poppler、Playwright Chromium 及中文字体；新电脑不需要先安装 Node、Python 或 Codex 桌面版。

## 在新电脑启动

1. 将 ZIP 完整解压到一个可写文件夹，例如 `D:\WenhengReview`，不要直接在压缩包内运行。无需保持原电脑的盘符、用户名或目录。
2. 可先双击 `CHECK-WINDOWS.cmd` 做本地自检。它不会提交论文或调用付费模型。
3. 双击 `START-WINDOWS.cmd`。窗口出现 `Review backend: http://127.0.0.1:4173` 后，用浏览器打开这个地址。
4. 使用原账号密码登录。账号、历史评审、补充重点和论文都保留。新电脑需要重新登录。
5. 保持启动窗口打开；结束使用时按 Ctrl+C 或关闭该窗口。再次启动仍使用同一个脚本。

首次启动会自动把数据库中论文、解析目录、调用记录和 PDF 报告的旧路径替换为当前解压目录，并检查关联文件、数据库完整性及外键。原始评审参数与提示词快照保持原样；再次移动解压目录后启动也会重新定位。请在服务停止后移动目录，不要同时启动同一份数据的两个服务。

## 模型配置

根目录 `.env` 已带上打包时的配置。GPT 五个模型共用 `CODEX_API_KEY`／`CODEX_BASE_URL`；DeepSeek Flash 和 Pro 共用 `DEEPSEEK_API_KEY`／`DEEPSEEK_BASE_URL`；解析继续使用 `MINERU_TOKEN`。如果新电脑网络访问服务地址受限，需要相应网络访问条件。

查看本地历史结果不需要调用模型；新论文解析与评审需要联网，且受各 API 账号余额和权限限制。修改 `.env` 后重启启动窗口生效。包内运行时路径由便携启动器自动设置，不需要保留旧电脑的 Codex 或 Poppler 路径。

这个迁移包包含论文、账号密码摘要和 API 密钥，是私人备份，请仅在自己的可信设备之间传递，不要上传公开仓库。没有打包 Codex 桌面登录会话、全局配置或其他项目。

## 包内容与数据库

- `data/review.sqlite3`：当前业务数据库的一致性快照，包含账号、论文、任务、结果、标准和证据关联。
- `data/` 的其他文件：原论文、解析结果、旧 JSON、历史备份、示例与审核记录。仅省略运行中的 WAL/SHM 侧文件和服务诊断日志；SQLite 文件通过备份 API 单独生成一致性快照。
- `src/`、`public/`、`migrations/`、`scripts/`、`tests/`、`docs/`：代码、数据库迁移、测试和说明。
- `assets/fonts/`：PDF 中文字体和许可。
- `node_modules/`、`runtime/`：Windows x64 运行组件，按原样保留。
- `portable-manifest.json`：原目录、数据库路径、运行组件版本、记录数量和缺失文件检查。
- `package-files.json`：初始包内文件大小及 SHA-256 清单，首次启动前可用于核对；启动后数据库路径和会话会正常变化。

压缩包没有 `.git`、开发临时目录或其他聊天资料。随包的旧审计／备份数据库用于归档；便携启动器只修复当前 `data/review.sqlite3`，不会把旧归档覆盖到当前业务数据。

## 常见问题

- **端口被占用**：关闭已有评审服务，或在 `.env` 中设置其他 `REVIEW_PORT` 后重启。
- **缺少关联文件／运行组件**：确认已完整解压，不要只复制数据库或单个 exe；可重新解压到一个新目录核对。
- **安全软件拦截程序或缺少系统 DLL**：先运行自检查看具体组件。该包在当前 Windows x64 上完成迁移路径和运行组件验证；新电脑仍需兼容的 Windows 系统及其标准系统组件。
- **需要恢复**：关闭服务，先保留当前数据，再把本迁移包解压到另一个新目录启动。不要覆盖正在使用的数据库。
- **macOS／Linux／Windows ARM**：此便携运行时不适用，需要按 `docs/upgrade.md` 安装对应平台依赖，代码和 SQLite 数据本身可以迁移。
